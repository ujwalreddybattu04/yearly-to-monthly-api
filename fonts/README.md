# Bundled PDF and chart font

UnicodeSans-Regular.ttf is the weight-400 static instance of Noto Sans CJK SC, renamed API Unicode Sans. It covers CJK (Chinese, Japanese, Korean), Latin, Greek, and Cyrillic characters supported by the source font. It does not claim coverage of every Unicode script or emoji.

Generated using fontTools.varLib.instancer at wght=400, retaining the full character repertoire. Only font name records were renamed after instancing. Both Matplotlib and ReportLab use this same bundled file, including on Render.

Matplotlib-shipped DejaVu Sans is also used by both renderers as a fallback for glyphs outside this CJK font, such as accented Greek. That font is supplied by the installed Matplotlib distribution under its included font license; it is not redistributed in this directory.
